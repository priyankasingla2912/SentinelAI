# SentinelAI - Product Requirements Document (PRD)

## Product Name
SentinelAI

## Vision
Build an Enterprise Agentic AI Fraud Intelligence Platform that helps financial institutions detect fraud, explain AI decisions, retrieve compliance knowledge, and assist fraud analysts with intelligent recommendations.

## Problem Statement
Banks process millions of transactions every day. Traditional fraud detection systems often generate too many false positives, lack explainability, and require analysts to manually investigate alerts. SentinelAI aims to reduce investigation time while improving fraud detection accuracy using Machine Learning, Explainable AI, RAG, and Agentic AI.

## Target Users
- Fraud Analyst
- Risk Manager
- Compliance Officer
- Executive

## MVP Features
- Fraud Detection
- Risk Score
- SHAP Explanation
- AI Investigation Summary
- Dashboard

## Technology Stack
Frontend: React / Next.js
Backend: FastAPI
Database: PostgreSQL
Machine Learning: XGBoost
Explainability: SHAP
Agent Framework: LangGraph
Knowledge Retrieval: RAG
